commands

config

all Postfix parameters and their values

postconf

value of a parameter

postconf [parameter]

all parameters explicitly set in main.cf

postconf -n

default values

postconf -d

defualt value of a given parameter

postconf -d alias_maps

queue

all mail in queue

postqueue -p

flush the queue (try to send)

postqueue -f

Delete an email from the queue (ids can be found in maillog)

postsuper -d [id]

delete all from queue

postsuper -d ALL

read message in queue

postcat -q [messageid]

logging

egrep '(reject|warning|error|fatal|panic):' /var/log/maillog
